# 网页操作 / Browser workflow

使用用户提供的部署 URL；打开左侧底部 Skills 可查看本页。工具必须支持浏览器上传/下载；只有网页搜索或读取 HTML 的客户端无法执行计算。

## 上传与主色

1. 用“上传图片”的 `input[type=file]` 选择用户图片。等待文件名更新，`.dominant-grid[aria-busy="false"]`，没有“原图颜色统计失败”。上传后工作台会自动完成默认分色，分析主色不必修改该结果。
2. 从“颜色映射”读取 `.dominant-card` 内的主色、占比和 px；`.color-map-stats strong` 为精确唯一 RGB 数，不是图层数。不要取下方 `.layer-card` 来充当原图统计。
3. 点色卡查看 9 个只读推荐。每项显示材料系列、中文名称、HEX、色号。主色卡右侧小锁单独控制固定颜色，点卡本身不锁色，也不换图层颜色。

## 分色与处理

先结合 SKILL.md 问清打印优先/细节优先、颜色数量与必要的尺寸喷嘴。优先用语义 role/name 定位，CSS 仅在缺少语义时使用；界面以当前文案为准。

| 控制 | 可用定位/名称 |
| --- | --- |
| 颜色数量输入 | spinbutton，name `颜色数量`，2–36 |
| 原图主色锁 | button，name `锁定原图颜色 #RRGGBB`，aria-pressed |
| 解锁所有主色 | button `全部解锁` |
| 算法 | button `按打印尺寸` / `手动块面`；按打印尺寸下 `bigchx-K 轮廓` / `像素方块` |
| 喷嘴/方向 | combobox `打印喷嘴` (.2/.4 mm) / `打印摆放方向` (flat/vertical) |
| 成品尺寸 | spinbutton `成品宽度 (cm)` / `成品高度 (cm)` |
| 厚度 | spinbutton `模型厚度 (mm)` |
| 层高/线宽 | spinbutton `层高 (mm)` / `线宽 (mm)` |
| 图片处理 | `曝光`、`对比度`、`饱和度`、`原图锐化`、`低像素模糊` |
| 分色清理 | `边界平滑`、`消除孤立像素` |
| 明确计算 | button `重新计算分色`；等待不再 disabled，`.print-status-footer` 成功状态 |

颜色数量、图片滑块支持直接输入；部分打印数值字段在失焦/Enter 才提交。原图锁定期间数量滑块、输入和数量重置均禁用，不强行操作。参数调整后等“正在缓冲预览…”结束；打印参数不触发处理预览。每次不必触发分色，全部设好后点击一次。计算失败读状态文字；“停止计算”可取消，已完成的结果不要当成这次的新结果。

“下载合并图”保存当前分色编辑的透明 PNG。这张图才是要交付的分色预览，原始图像或处理预览不能替代它。

## 配色与手动编辑

独立图层有 `Layer 01 HEX 色值`、`Layer 01 手动改色` 等输入，以及官方耗材搜索、类型筛选和推荐按钮。用户要“PLA Matte 的某色”时选择实际目录项；手动改 HEX 不会保留先前的材料身份。

眼睛隐藏当前图层，同时从原图遮罩排除其区域再算其余部分；透明孔洞保留。恢复眼睛重新纳入该区域。图层锁保持图层颜色，原图锁需在颜色映射解开。

分色编辑支持滚轮缩放、中键平移；像素选择、框选与画笔将来源层的选区分配给目标层，确认后改标签并适配目标颜色。使用底部右下角适应窗口恢复视图。原始图像/处理预览也支持左键拖动平移。

“重新计算分色”从处理后的整张原图开始并清除隐藏遮罩；会重建先前局部标签编辑。想导出隐藏/手改的结果时，直接使用当前结果生成模型。“初始化”会重置参数与锁定，不能为解决等待状态随意点击。

## 导出

1. 已确定打印机时，在“模型生成与导出”选择 `打印机型`。检查 mm 尺寸、适配状态和厚度；若打印参数待重新分色，先更新分色；只改颜色/厚度需要重新生成模型，无需重聚类。
2. 点击“生成模型预览”。等“当前模型已生成”，查看实际 3D 平放模型。中键平移、左键旋转、滚轮缩放。
3. 点击“下载 3MF / STL / SVG”。等下载完成，保存 ZIP，提取 `bigchx-make-model.3mf` 并返回该文件和 PNG。不能只告诉用户浏览器下载了却没有交付工具获取的文件。
4. 下载 3MF 后在 Bambu Studio 打开为项目，不要选择“仅加载几何”。不要分别居中每层 STL。若用户只要预览，不强制进行模型生成。

普通浏览器工具无法执行本地 Node 脚本时，使用这些真实 UI 操作即可；不要发明 `/api/separate`、`window.bigchx` 等不存在的接口。
